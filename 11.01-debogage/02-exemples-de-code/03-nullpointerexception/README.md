# Exemple : NullPointerException

Cet exemple illustre une erreur de référence nulle avec :

- Tentative d'utiliser un objet qui est `null`.
- Exception au moment de l'exécution.
- Utilisation du débogueur pour remonter à la source du problème.

**Mission** : Utiliser le débogueur pour identifier quel objet est `null` et
pourquoi.

## Compilation et exécution

```bash
javac Main.java
java Main
```

**Note** : Ce programme plante avec une NullPointerException. Trouvez quel objet
est `null` !
