# Exemple : Erreur de condition

Cet exemple illustre des erreurs dans les conditions avec :

- Utilisation de `=` au lieu de `==`.
- Conditions inversées ou incorrectes.
- Opérateurs logiques mal utilisés (`&&` vs `||`).

**Mission** : Utiliser le débogueur pour identifier les conditions incorrectes.

## Compilation et exécution

```bash
javac Main.java
java Main
```

**Note** : Certains cas ne fonctionnent pas comme prévu. Utilisez des
breakpoints conditionnels !
