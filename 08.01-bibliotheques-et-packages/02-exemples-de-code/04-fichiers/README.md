# Exemple : Lecture et écriture de fichiers

Cet exemple illustre l'utilisation de `java.io` avec :

- Écriture de texte dans un fichier.
- Lecture ligne par ligne d'un fichier.
- Gestion automatique des ressources avec try-with-resources.
- Gestion des exceptions d'entrée/sortie.

## Compilation et exécution

```bash
javac Main.java
java Main
```

L'exemple crée un fichier `notes.txt` dans le répertoire courant.
