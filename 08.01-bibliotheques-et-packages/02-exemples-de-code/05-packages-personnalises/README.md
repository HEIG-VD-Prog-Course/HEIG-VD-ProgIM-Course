# Exemple : Packages personnalisés

Cet exemple illustre la création et l'utilisation de packages personnalisés avec
:

- Déclaration de packages avec `package`.
- Organisation des classes dans différents packages.
- Modificateurs de visibilité (`public`, `private`, package-private).
- Import de classes depuis des packages personnalisés.
- Documentation Javadoc.

## Compilation et exécution

```bash
javac models/*.java utils/*.java Main.java
java Main
```

Ou pour compiler et exécuter en une seule commande :

```bash
javac models/*.java utils/*.java Main.java && java Main
```
