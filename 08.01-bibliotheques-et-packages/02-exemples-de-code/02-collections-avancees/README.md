# Exemple : Collections avancées

Cet exemple illustre l'utilisation de collections de `java.util` avec :

- `HashMap` pour stocker des paires clé-valeur.
- `Random` pour générer des nombres aléatoires.
- `Collections` pour trier et mélanger des listes.
- Démonstration de manipulation avancée de collections.

## Compilation et exécution

```bash
javac Main.java
java Main
```
