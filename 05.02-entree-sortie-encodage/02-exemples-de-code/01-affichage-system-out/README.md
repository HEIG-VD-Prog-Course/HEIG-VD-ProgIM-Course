# Exemple : Affichage avec System.out

Cet exemple illustre les différentes méthodes d'affichage en Java avec :

- `System.out.print()` : affiche sans retour à la ligne
- `System.out.println()` : affiche avec retour à la ligne
- `System.out.printf()` : affiche avec formatage
- Concaténation de chaînes avec l'opérateur `+`

## Compilation et exécution

```bash
javac Main.java
java Main
```
