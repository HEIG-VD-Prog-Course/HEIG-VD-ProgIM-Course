# Exemple : Tri à bulles

Cet exemple illustre le tri à bulles avec :

- Implémentation du tri à bulles (Bubble Sort).
- Affichage des étapes du tri.
- Comptage du nombre d'échanges et de comparaisons.
- Optimisation avec détection de tableau déjà trié.

## Compilation et exécution

```bash
javac Main.java
java Main
```
