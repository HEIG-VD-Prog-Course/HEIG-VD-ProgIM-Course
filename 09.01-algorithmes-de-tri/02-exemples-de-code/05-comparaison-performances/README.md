# Exemple : Comparaison des performances

Cet exemple illustre la comparaison des algorithmes de tri avec :

- Mesure du temps d'exécution pour différents algorithmes.
- Tests sur différentes tailles de tableaux.
- Comparaison entre algorithmes simples (O(n²)) et efficaces (O(n log n)).
- Utilisation de `Arrays.sort()` comme référence.
- Visualisation des différences de performance.

## Compilation et exécution

```bash
javac Main.java
java Main
```

**Note** : L'exécution peut prendre quelques secondes pour les grands tableaux.
