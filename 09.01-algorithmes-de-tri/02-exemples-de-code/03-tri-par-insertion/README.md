# Exemple : Tri par insertion

Cet exemple illustre le tri par insertion avec :

- Implémentation du tri par insertion (Insertion Sort).
- Insertion d'éléments dans une partie déjà triée.
- Affichage des étapes pour visualiser les insertions.
- Démonstration de l'adaptativité (efficace sur tableaux presque triés).

## Compilation et exécution

```bash
javac Main.java
java Main
```
