# Exemple : Tri fusion

Cet exemple illustre le tri fusion avec :

- Implémentation du tri fusion (Merge Sort) récursif.
- Division du tableau en sous-tableaux.
- Fusion de tableaux triés.
- Affichage des étapes de division et fusion.
- Complexité O(n log n) garantie dans tous les cas.

## Compilation et exécution

```bash
javac Main.java
java Main
```
