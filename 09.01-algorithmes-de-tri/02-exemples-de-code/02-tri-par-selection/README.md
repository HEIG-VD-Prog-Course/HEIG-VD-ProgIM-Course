# Exemple : Tri par sélection

Cet exemple illustre le tri par sélection avec :

- Implémentation du tri par sélection (Selection Sort).
- Recherche du minimum à chaque itération.
- Affichage des étapes pour comprendre le fonctionnement.
- Comptage du nombre d'échanges (toujours n-1 échanges).

## Compilation et exécution

```bash
javac Main.java
java Main
```
