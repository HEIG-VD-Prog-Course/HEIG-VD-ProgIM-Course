# Préparation au test

Bienvenue dans le module de préparation au test !

Ce module vous aidera à vous préparer pour le test de programmation qui évaluera
vos connaissances acquises jusqu'à présent.

## Contenu du module

- [Support de cours](01-supports-de-cours/README.md) - Informations sur le
  format du test et conseils de préparation
- [Quiz de révision](01-supports-de-cours/PRESENTATION.md) - Questions de
  révision sous forme de quiz

## Format du test

Le test se compose de **deux parties** :

1. **Partie papier** : Dessiner des schémas UML et répondre à des questions
   théoriques
2. **Partie sur ordinateur** : Utiliser la plateforme d'évaluation de la HEIG-VD
   pour exécuter du code Java et répondre à des questions

## Objectifs

- Réviser les concepts clés vus pendant le cours
- Se familiariser avec le format du test
- S'entraîner avec des questions des années précédentes
- Identifier les points à approfondir
