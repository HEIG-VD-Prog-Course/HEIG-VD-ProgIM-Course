## Introduction

Ce document vous présente le format du test et vous donne des conseils pour bien
vous préparer. Le test évalue vos connaissances et compétences acquises dans les
modules précédents.

**Objectif du test** : Vérifier que vous maîtrisez les concepts fondamentaux de
la programmation en Java et que vous êtes capable de les appliquer pour résoudre
des problèmes simples.

## Format du test

Le test se compose de **deux parties distinctes** :

### Partie 1 : Épreuve sur papier

Cette partie évalue votre compréhension théorique et votre capacité à modéliser
des problèmes.

**Contenu** :

- **Schémas UML** : Vous devrez dessiner des diagrammes pour représenter des
  algorithmes (diagrammes d'activité, diagrammes de séquence, etc.)
- **Questions théoriques** : Questions sur les concepts vus en cours (types de
  données, structures de contrôle, etc.)
- **Lecture et analyse de code** : Comprendre ce que fait un programme et
  prédire son résultat

**Ce qu'on attend de vous** :

- Dessiner des schémas UML clairs et corrects
- Expliquer les concepts avec vos propres mots
- Analyser du code sans l'exécuter

**Exemple de questions** :

- "Dessinez le diagramme d'activité d'un programme qui demande un nombre à
  l'utilisateur et affiche s'il est pair ou impair"
- "Expliquez la différence entre une boucle `while` et une boucle `do...while`"
- "Que va afficher ce programme ? (code fourni)"

### Partie 2 : Épreuve sur ordinateur

Cette partie évalue votre capacité à écrire et à exécuter du code Java.

**Contenu** :

- **Écriture de code Java** : Vous devrez écrire des programmes pour résoudre
  des problèmes
- **Débogage** : Corriger des erreurs dans du code fourni
- **Questions théoriques** : Questions à choix multiples ou à réponse courte sur
  la plateforme

**Plateforme utilisée** :

Vous utiliserez la **plateforme d'évaluation de la HEIG-VD**. Cette plateforme
permet de :

- Écrire du code Java dans un éditeur en ligne
- Compiler et exécuter votre code
- Soumettre vos réponses
- Répondre à des questions théoriques

**Ce qu'on attend de vous** :

- Écrire du code Java qui compile et s'exécute correctement
- Résoudre des problèmes de programmation simples
- Utiliser les bonnes pratiques vues en cours (nommage, formatage, etc.)

**Exemple de questions** :

- "Écrivez une méthode qui prend un tableau d'entiers en paramètre et retourne
  la somme de ses éléments"
- "Corrigez les erreurs dans ce code pour qu'il compile"
- "Quelle est la valeur de la variable `x` à la fin de ce programme ?"

## Durée et organisation

- **Durée totale** : À définir par votre enseignant
- **Partie papier** : Première partie du test
- **Partie ordinateur** : Seconde partie du test
- **Matériel autorisé** : Ordinateur personnel avec accès à la plateforme
  d'évaluation, papier et stylo pour la partie papier

## Questions fréquentes

**Q : Puis-je utiliser mes notes pendant le test ?**  
R : Non. Le test évalue vos connaissances personnelles.

**Q : La plateforme d'évaluation compile-t-elle automatiquement mon code ?**  
R : Oui, la plateforme compile et exécute votre code. Vous verrez les erreurs de
compilation et le résultat de l'exécution.

**Q : Que se passe-t-il si mon code ne compile pas ?**  
R : Vous devrez corriger les erreurs avant de pouvoir soumettre votre réponse.
Prenez le temps de bien relire votre code.

**Q : Les schémas UML doivent-ils être parfaits ?**  
R : Ils doivent être corrects et lisibles, mais on ne vous demande pas une
perfection artistique. L'important est que le schéma représente correctement
l'algorithme.

**Q : Puis-je utiliser Internet pendant la partie sur ordinateur ?**  
R : Non. Le test évalue vos connaissances personnelles.

**Q : Les questions sont-elles similaires à celles des questionnaires des années
précédentes ?**  
R : Oui, le format et le niveau de difficulté sont similaires. C'est pourquoi il
est important de s'entraîner avec ces questionnaires.

## Conclusion

Le test est une opportunité de montrer ce que vous avez appris et de valider vos
compétences. Avec une bonne préparation, vous devriez pouvoir le réussir sans
problème.

**Rappel des points clés** :

- Le test comporte deux parties : papier et ordinateur
- Révisez tous les thèmes vus en cours
- Entraînez-vous avec les questionnaires des années précédentes
- Pratiquez régulièrement la programmation
- Gérez bien votre temps pendant le test
- Restez calme et confiant

**Bonne préparation et bon courage pour le test !**
