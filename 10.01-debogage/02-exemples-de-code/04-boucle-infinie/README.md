# Exemple : Boucle infinie

Cet exemple illustre une boucle infinie avec :

- Oubli d'incrémentation dans une boucle `while`.
- Programme qui ne s'arrête jamais.
- Utilisation du débogueur pour identifier la variable qui ne change pas.

**Mission** : Utiliser le débogueur pour trouver pourquoi la boucle ne se
termine jamais.

## Compilation et exécution

```bash
javac Main.java
java Main
```

**Note** : Ce programme ne se termine pas ! Utilisez Ctrl+C pour l'arrêter, puis
déboguez-le.
