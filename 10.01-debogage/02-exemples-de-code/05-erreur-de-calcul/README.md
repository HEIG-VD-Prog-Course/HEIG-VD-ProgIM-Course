# Exemple : Erreur de calcul

Cet exemple illustre des erreurs de calcul subtiles avec :

- Problèmes d'ordre d'opérations.
- Erreurs d'arrondi avec les nombres à virgule flottante.
- Dépassement de capacité (overflow).

**Mission** : Utiliser le débogueur et la section WATCH pour identifier les
calculs incorrects.

## Compilation et exécution

```bash
javac Main.java
java Main
```

**Note** : Les résultats ne correspondent pas aux attentes. Utilisez WATCH pour
surveiller les expressions !
