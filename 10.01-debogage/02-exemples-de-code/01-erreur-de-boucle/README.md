# Exemple : Erreur de boucle

Cet exemple illustre une erreur de boucle classique avec :

- Dépassement d'indice dans un tableau.
- Bug causé par une condition de boucle incorrecte (`<=` au lieu de `<`).
- Utilisation du débogueur pour identifier l'erreur.

**Mission** : Utiliser le débogueur VS Code pour identifier et corriger le bug.

## Compilation et exécution

```bash
javac Main.java
java Main
```

**Note** : Ce programme contient un bug intentionnel qui cause une exception.
Utilisez le débogueur pour le trouver !
