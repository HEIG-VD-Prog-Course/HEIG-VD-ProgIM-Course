# Exemple : Erreur logique

Cet exemple illustre une erreur logique avec :

- Un programme qui compile et s'exécute sans erreur.
- Un résultat incorrect dû à une logique défectueuse.
- Messages inversés dans une condition.

**Mission** : Utiliser le débogueur pour identifier pourquoi les résultats sont
incorrects.

## Compilation et exécution

```bash
javac Main.java
java Main
```

**Note** : Ce programme ne plante pas, mais produit des résultats incorrects.
C'est une erreur logique !
