# Exemple : Recherche dans des objets

Cet exemple illustre la recherche dans des collections d'objets avec :

- Recherche par critère dans une liste d'objets.
- Utilisation de classes personnalisées.
- Implémentation de méthodes de recherche spécifiques.
- Recherche multiple par différents attributs.

## Compilation et exécution

```bash
javac Main.java
java Main
```
