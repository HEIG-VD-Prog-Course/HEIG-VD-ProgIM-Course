# Exemple : Recherche linéaire simple

Cet exemple illustre la recherche linéaire dans un tableau avec :

- Implémentation basique de la recherche linéaire.
- Parcours séquentiel d'un tableau.
- Retour de l'index de l'élément trouvé.
- Gestion du cas où l'élément n'est pas trouvé.

## Compilation et exécution

```bash
javac Main.java
java Main
```
