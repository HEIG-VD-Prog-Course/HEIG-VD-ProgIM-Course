# Exemple : Parcours de tableaux 2D

Cet exemple illustre la recherche dans des tableaux multidimensionnels avec :

- Parcours de matrices (tableaux 2D).
- Recherche d'éléments dans une grille.
- Recherche de motifs (ligne, colonne, diagonale).
- Calcul de statistiques sur une matrice.

## Compilation et exécution

```bash
javac Main.java
java Main
```
