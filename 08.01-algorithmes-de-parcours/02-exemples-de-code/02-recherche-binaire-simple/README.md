# Exemple : Recherche binaire simple

Cet exemple illustre la recherche binaire dans un tableau trié avec :

- Implémentation de la recherche binaire itérative.
- Division répétée de la zone de recherche.
- Calcul de l'élément du milieu.
- Comparaison avec la recherche linéaire.

## Compilation et exécution

```bash
javac Main.java
java Main
```
