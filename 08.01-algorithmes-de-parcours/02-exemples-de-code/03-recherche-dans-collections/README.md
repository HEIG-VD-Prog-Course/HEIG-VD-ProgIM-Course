# Exemple : Recherche dans des collections

Cet exemple illustre la recherche dans différentes collections Java avec :

- Utilisation de `indexOf()` et `contains()` dans ArrayList.
- Utilisation de `Arrays.binarySearch()` pour les tableaux.
- Utilisation de `Collections.binarySearch()` pour les listes.
- Comparaison des méthodes intégrées de Java.

## Compilation et exécution

```bash
javac Main.java
java Main
```
